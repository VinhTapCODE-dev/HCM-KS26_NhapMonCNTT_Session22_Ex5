### Mẫu Bug Report Template:

- **Context**: Hệ điều hành, phiên bản công cụ đang chạy lệnh hoặc dự án nào.

- **Expected**: Kết quả đúng ra phải xảy ra.

- **Actual**: Kết quả đang xảy ra.

- **Log & Screenshot**: Dán nguyên văn dòng lỗi và ảnh chụp màn hình.
### Quy trình 3 bước tra cứu bắt buộc: 

- **Bước 1: Googling**:

Tách lỗi thành 3 phần: Ứng dụng + Mã lỗi + Hệ điều hành.

Dùng toán tử tìm kiếm: " " để khớp đúng cụm lỗi, - để loại kết quả không liên quan, site: để tìm trong một trang cụ thể.

- **Bước 2: Community Search**:

Đọc lướt khoảng 30 giây, ưu tiên câu trả lời có tích xanh (Accepted Answer) và nhiều Upvote.

Kiểm tra mốc năm của câu trả lời, vì bài quá cũ có thể không còn đúng với phiên bản hiện tại.

Trên GitHub Issues, tìm cách sửa tạm (Workaround) nếu lỗi chưa được vá.

- **Bước 3: AI Translation**:

Viết prompt 3 phần: Context (bối cảnh) + Raw Error (lỗi nguyên văn) + Instruction (yêu cầu AI giải thích và hướng dẫn sửa).

Ba nguyên tắc an toàn: không copy lệnh mù quáng mà phải hiểu lệnh làm gì, cẩn thận với ảo giác AI, và không gửi API Key hay thông tin bảo mật cho AI.
